# Yo‘l xaritasi (Roadmap) — ImageRights.uz

Maqsad: Markaziy Osiyodagi birinchi professional tasvir huquqlari himoyasi
ekotizimini qurish va investitsiyaga tayyor mahsulotga aylantirish.

## ✅ Bosqich 0 — Poydevor (joriy)
- Premium landing sahifa (hero, muammo, yechim, funksiyalar, tariflar, FAQ).
- Professional dashboard — 8 ta modul UI.
- NestJS API skeleti + to‘liq Prisma sxema.
- Autentifikatsiya (email/JWT), RBAC, audit log modeli.
- Arxitektura, API, DB va xavfsizlik hujjatlari.

## 🚧 Bosqich 1 — MVP (0–3 oy)
- AWS S3 presigned upload integratsiyasi.
- OneID va Google OAuth oqimlari.
- Real deepfake detection modeli integratsiyasi.
- Reverse image search (pHash + vektor qidiruv) ishga tushirish.
- To‘lov tizimi (Click/Payme + xalqaro kartalar).

## 🔜 Bosqich 2 — O‘sish (3–6 oy)
- 24/7 fon monitoring worker’lari va navbat (BullMQ/Redis).
- AI yuridik yordamchini generativ modelga ulash.
- Litsenziyalash bozori + elektron shartnoma imzolash.
- Mobil PWA va push-bildirishnomalar.
- Admin panel: foydalanuvchilar, to‘lovlar, analitika, kontent.

## 🌍 Bosqich 3 — Miqyoslash (6–12 oy)
- Mikroservislarga bosqichma-bosqich ajratish.
- Ko‘p tilli interfeys (uz / ru / en).
- Davlat organlari va OAV uchun Enterprise integratsiyalari.
- SOC2 / ISO 27001 yo‘nalishidagi muvofiqlik ishlari.
- Markaziy Osiyo bozorlariga kengayish (KZ, KG, TJ).

## 📊 Biznes ko‘rsatkichlari (KPI)
- Faol foydalanuvchilar (MAU), konversiya, ARPU.
- Aniqlangan va muvaffaqiyatli hal qilingan huquqbuzarliklar soni.
- Litsenziyalash bozori aylanmasi.
